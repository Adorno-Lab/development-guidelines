# Use of AI Tools

Which AI tools can be used for work in the Adorno Lab.

> [!CAUTION]
>
> To prevent information leakage and export-control violations, **do not use any AI tool other than the university-approved Copilot** for any work-related task.


## Core Principles

1. **Only the approved tool** — The university-approved Copilot is the only AI tool allowed for work.
2. **All work-related tasks** — The rule applies to everything related to work, not only to code: for example, source code, documentation, data, papers, reports, and emails.
3. **When in doubt, ask** — If you are not sure whether a tool or a task is covered, ask the project lead before using it.
